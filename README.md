## Featured

**[valupro](https://valupro.pro)** · CRM and valuation report software for Kenyan registered valuers. A firm runs enquiries and quotes, inspects and values a property, passes QA checks, then issues a signed, sealed PDF report that banks verify by QR code. Next.js 16 and React 19, Neon Postgres with Drizzle, Vercel Blob for photos and seals, Paystack billing in KES by card or M-Pesa, PDFs via `@react-pdf/renderer`.

**[Transcribez](https://transcribez.xyz)** · AI transcription and translation SaaS built on Anthropic's Claude. Live in production with 900+ users. Prompt engineering, structured segment output, multi-language translation, anti-hallucination guardrails, and model routing (Sonnet/Haiku) for quality versus cost.
